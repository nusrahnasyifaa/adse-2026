# ASEAN Data Science Explorers 2026

### Overview
* These hands-on workshops provide foundational knowledge in data analytics and storytelling
* For data visualization and building storyboards

Key Tool: ** SAP Analytics Cloud (SAC) ** 

SAP Analytics Cloud is SaaS based Analytic tool and is a part of HANA Cloud platform. This is a handy tool for business users for analytical and ad-hoc reporting. Using SAP Analytics Cloud, business users can create basic, medium, and complex dashboard from transactional data in database to meet business requirements.
